# ALPAKON — Industrial, podgląd dla klienta

Statyczna wizytówka przygotowana na GitHub Pages. Brak panelu administracyjnego, serwera i zapisu danych. Galeria zawiera trzy lokalne fotografie poglądowe. Zachowane filtrowanie i podgląd zdjęć. Logo i zdjęcia znajdują się w assets/. Czcionki są pobierane z Google Fonts.

## Publikacja

1. Utwórz PUBLICZNE repozytorium alpakon na koncie mysza-cloud. Nie zmieniaj repozytorium portfolio mysza-cloud.github.io.
2. Wgraj ZAWARTOŚĆ tego folderu do głównego katalogu repozytorium: index.html, informacje.html i katalog assets. Plik .nojekyll jest opcjonalny dla tej strony.
3. W Settings → Pages wybierz Deploy from a branch, gałąź main, katalog / (root), następnie Save.
4. Poczekaj na zakończenie publikacji. Oczekiwany adres przy tej nazwie repozytorium: https://mysza-cloud.github.io/alpakon/ — adres działa dopiero po publikacji.

Można otworzyć index.html bezpośrednio z dysku. Nie ma instalacji ani budowania.

## Przed publiczną prezentacją

Repozytorium i strona będą publiczne. noindex jest wskazówką dla wyszukiwarek, nie ochroną dostępu. Fotografie są poglądowe, nie są realizacjami ALPAKON. Logo jest rekonstrukcją z archiwalnej miniatury. Kontakt i oferta wymagają potwierdzenia właścicieli.
